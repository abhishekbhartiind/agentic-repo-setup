# Routing for Claude Code

Profiles live in `.claude/agents/` (generated by `.ai/scripts/generate-claude-agents.mjs`). Each profile fixes only `effort` and has `model: inherit`; the coordinator selects the model by passing the `model` alias in the Agent tool call (Claude Code resolves a per-invocation `model` before the profile's frontmatter). Aliases are the current Claude Code aliases: `opus`, `sonnet`, `haiku`.

| Stage | Role | Profile (default effort) | Model alias | Effort variants |
| --- | --- | --- | --- | --- |
| simple | code-simple | `code-simple-low` | `haiku` | `code-simple-low`, `code-simple-medium`, `code-simple-high` |
| research | code-researcher | `code-researcher-medium` | `sonnet` | `code-researcher-low`, `code-researcher-medium`, `code-researcher-high` |
| plan | code-planner | `code-planner-high` | `opus` | `code-planner-low`, `code-planner-medium`, `code-planner-high` |
| implement | code-implementer | `code-implementer-medium` | `sonnet` | `code-implementer-low`, `code-implementer-medium`, `code-implementer-high` |
| review | code-reviewer | `code-reviewer-high` | `opus` | `code-reviewer-low`, `code-reviewer-medium`, `code-reviewer-high` |
| audit | auditor | `auditor-high` | `opus` | `auditor-low`, `auditor-medium`, `auditor-high` |

## Choosing effort

- `low`: mechanical, single-file, well-specified.
- `medium`: default for research and implementation.
- `high`: planning, review and audit; also anything touching auth, env/build config or dependency upgrades; also a retry after a rejected artifact.

## Notes

- Which effort levels a model supports depends on the model (Claude Code docs); if a level is not supported for the chosen model Claude Code applies its own fallback. Verify with a real delegation before relying on `haiku` + `low/high`.
- Restricted roles (researcher, planner, reviewer, auditor) are constrained by the PreToolUse hook; see `.ai/scripts/guard-claude-role-write.mjs`.
- Memory-enabled roles (researcher, reviewer, auditor) keep memory per agent name in `.claude/agent-memory/<profile name>/`.
